# Bamboo Calendar

Create a cross-platform web application (optimized for Mobile, Tablet, Laptop, and PC) inspired by the Skylight Calendar, but with a calming, nature-inspired "Bamboo" theme. Use a palette of soft sage greens, warm off-whites, and earthy wood/bamboo accents with clean typography.



Set up the following core data and user structure:

1. Multi-User/Household Account: A master account can host multiple "Profiles" (e.g., Mom, Dad, Kid 1, General Kitchen Calendar).

2. Profile Switcher: A quick, PIN-protected or one-tap way to switch between profiles from a main sidebar or top navigation.

3. Master Database: A centralized database structure where events, tasks, and data are tagged by Profile ID, allowing for a combined "Family View" or individual "Profile Views."



Build a beautiful, responsive main sidebar and top navigation that reflects this Bamboo aesthetic and allows easy profile switching.
